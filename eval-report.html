Context

We built a small demo. It sends each prompt to the right store. There are two stores. One holds work info like meetings and projects. The other holds life info like health and family.

For each prompt we ask the model two yes or no questions. Could the work store help? Could the life store help? Each answer is a number from 0 to 1. Our code says yes when the number is 0.5 or more. Both can be yes. So a prompt like "do I have anything tomorrow morning?" goes to both stores.

The test file is eval.py. It has 30 prompts we wrote by hand. 10 should go to work. 10 should go to life. 10 should go to both. We check each one against the live model. The code lives in this repo: github.com/TyrellD1/typesafe-ai_smoke-test.

Timing and cost

Each row is one API call. The call takes about 1.35 seconds on average (slowest was 6.55s). The whole run used 15615 input tokens and 1170 output tokens. That works out to about 28.9 output tokens per second.

A few notes on these numbers. The time is measured on our side, so it includes the network trip. The token counts come straight from the API. The tokens per second is our own math (output tokens divided by time), so treat it as rough. Both questions ride in the same call, so asking the second one costs almost nothing extra. Slowest calls this run: W07 (6.55s); L10 (5.47s); L04 (4.44s).
